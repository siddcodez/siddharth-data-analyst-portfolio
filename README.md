# 🚀 Siddharth Tomar | Data Analyst Portfolio

Welcome to the repository for my personal portfolio website! This site showcases my skills, upcoming projects, and journey in Data Analytics and Data Science with interactive 3D elements and smooth animations.

## 🔥 Features

- **3D Interactive Skills Keyboard**: Custom interactive keyboard built with Spline featuring Data Analytics and Data Science keycaps that reveal details on hover and keypress.
- **Slick Interactions**: Powered by GSAP and Framer Motion for smooth transitions, particle backgrounds, and responsive layouts.
- **Modern Dark Theme**: Tailored palette optimized for clarity and high aesthetic contrast.
- **Responsive Design**: Fully responsive across mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

- **Framework**: Next.js 14, React, Tailwind CSS, TypeScript
- **3D & Animations**: Spline Runtime, GSAP, Framer Motion, Lucide Icons
- **Deployment**: Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/siddcodez/siddharth-data-analyst-portfolio.git
    ```

2. Navigate to the project directory:

    ```bash
    cd siddharth-data-analyst-portfolio
    ```

3. Install dependencies:

    ```bash
    npm install
    ```

4. Run the development server:

    ```bash
    npm run dev
    ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
